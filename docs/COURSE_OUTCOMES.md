# Course outcomes and evidence

LeetGrammar's outcome claims are text-first performance claims. They are not proficiency ratings. The course does not claim listening, speaking, pronunciation, or uncaptioned-media competence.

The executable outcome map lives in `src/data/course-outcomes.ts`. Tests fail when an implemented objective has no outcome, an outcome points at an untaught objective, or specific evidence points outside the approved vertical slice.

## Implemented can-do outcomes

1. I can find the WHO, SIGNAL, WHAT, and DO in a level-appropriate written Somali statement.
2. I can build short written Somali statements with the noun, signal, subject, and action forms I have learned.
3. I can notice when a first reading fails and use the signal or ending to repair it.
4. I can explain in plain English which Somali clue supports my reading.

## Evidence rules

- Guided retrieval and cold production show control of taught material.
- Context transfer reuses a sourced sentence in a new task. It does not count as unseen text.
- Unseen reading changes the text configuration while staying within taught, source-cleared material.
- Written interaction must repair or clarify an insufficient interpretation.
- Connected writing means more than one related sentence. The current bounded example is Lesson 8's two-line update.
- Delayed transfer comes from cumulative homework after the lesson.
- Open-ended writing is not treated as definitively machine-graded. Current production uses bounded answers and model comparison.

## Vertical-slice status

Lessons 1, 5, and 8 are the first implementation slice. Lesson 1 adds strategy transfer and whole-sentence retrieval. Lesson 5 adds signal-first repair of an insufficient reading. Lesson 8 adds new two-line parsing and bounded connected writing. Broader coverage remains planned work and is not counted as implemented evidence.
